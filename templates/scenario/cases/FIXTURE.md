# fixture 化の方針

⚠️ **実データをそのまま置かない。** 案件データには取引先名・個人名が入る。
**後から足すと、作ったケースを全部作り直すことになる**ので、置く前に必ず通す。

| 何を | どうする |
|---|---|
| 取引先名・法人名 | 一貫した架空名に置換（同じ実体は同じ架空名に） |
| 個人名 | 同上 |
| メールアドレス・電話番号・住所 | 形式だけ残して置換 |
| 社内固有の URL・ID | 置換。ただし公開記事の URL は残してよい |
| 数字（金額・件数） | **原則そのまま**（判定に効く）。特定に繋がるものだけ丸める |

置換したら、この表の下に「何をどう置換したか」を1行ずつ残す。
リポが private でも、置き場所ではなく**規約**として守る。

## 置換ログ

- （例）取引先A社 → 「株式会社サンプル商事」
