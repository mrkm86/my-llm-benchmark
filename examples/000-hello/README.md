# 000-hello — ハーネスが動くかを見るだけの段

**これは実力を測る段ではない。** 配線（モデルが呼べる / 判定が効く / レポートが出る）の確認用。
このリポに入っている**唯一のシナリオ**で、実データは1バイトも入っていない。

## この段が要求するもの

指示どおりの形で、短く、日本語で答える。どのモデルでも通るはずの高さにしてある。
**ここが落ちたらモデルではなく配線を疑う。**

## 判定方法

[機械] 失格条件のみ。正解は持たない。

| 項目 | 値 |
|---|---|
| ケース数 | 2 |
| 1ケースの合否 | 失格条件に1つも当たらない |
| 段の通過条件 | 全ケース × 全実行（既定3回）が合格 |

## 既知の限界

**通っても何も分からない。** カタログの行に書かないこと。
