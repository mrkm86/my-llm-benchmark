# 000-hello — 配線が生きているかを見るだけの段

**実力を測る段ではない。** モデルが呼べる / system が届く / 判定が効く / レポートが出る、の確認用。
実データは1バイトも入っていないので、この段だけは公開リポにも同じものが置いてある
（`my-llm-benchmark/examples/000-hello`。**両方を同じ内容に保つこと**）。

## 読み方 — ✅ と ❌ で意味が違う

| 結果 | 何が言えるか |
|---|---|
| ✅ 通った | **何も分からない。** カタログの「通った段」に書かない |
| ❌ 落ちた | **モデルではなく配線・梱包を疑う合図。** ここから先の 0/3 はモデルの実力ではない |

**❌ のほうが情報を持っている**という、この階段で唯一の段。

### 実際に効いた例（BB-374 / BB-375）

`granite4.2:3b-q8_0` は全5段 0/3 だったが、原因はモデルではなく
**ollama の tag が chat template レイヤを持たず、system が捨てられていた**こと。
当時は 001〜005 を全部流してから template を調べに行った。

000 を入れた後に同じ tag を流すと、**1段目で落ちる**:

```
WARN: this tag has no system slot in its template — folding the system prompt into the prompt
| 000-hello | 1 失格 | 0/3 | DISQUALIFIED: output has 10 non-blank lines (max 1) /
                              forbidden pattern hit: 見出しで飾った / コードブロックで囲んだ
```

**「日本の首都は」に10行で答えて見出しを付ける**なら、それは実力の話ではない。

## この段が要求するもの

指示どおりの形で、短く、日本語で答える。**どのモデルでも通る高さ**にしてある
（実測: 1.5B でも 3/3）。ここが落ちたら高さの問題ではない。

## 判定方法

[機械] 失格条件のみ。正解は持たない。

| 項目 | 値 |
|---|---|
| ケース数 | 3（`capital` 1行 / `one-number` 1行 / `three-lines` 3行） |
| 1ケースの合否 | 失格条件に1つも当たらない |
| 段の通過条件 | 全ケース × 全実行（既定3回）が合格 |

失格条件は `disqualifiers.md`。

## 既知の限界

- **通過はカタログの根拠にならない。** マトリクスには載せるが、「通った段」としては数えない
- **梱包の壊れを全部は捕まえない。** template が無くても、たまたま短く日本語で答えてしまえば通る。
  ⚠️ **`system prompt` 欄が `prepended` になっていないかは、結果と別に必ず目視する**
