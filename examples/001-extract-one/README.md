# 001-extract-one — 1件の構造化抽出

**測るもの: JSON が壊れず、値が原文と一致するか。**

| 項目 | 値 |
|---|---|
| ケース数 | 3 |
| 1ケースの合否 | JSON として読めて、`expected.json` の全キーが一致する |
| 段の通過条件 | 全ケース × 全実行（既定3回）が合格 |
| 正解 | **あり**（`cases/*/expected.json`）。**未検品** — `../REVIEW.md` |

## 正解を持てる理由

**答えが一意に決まるから。** 各ケースの原文には**測定値が1つだけ**入っている。
2つ入っている文を使うと、モデルがどちらを選んでも正当なのに落ちる。

```
✗ The stone is about 1.5 meter square and 0.3 meter thick.   ← 測定値が2つ
✓ The cast-iron trough cc was 1.6 centimeter thick.          ← 1つ
```

## 素材

Michelson & Morley (1887) の本文（Wikisource・パブリックドメイン）。
数値と単位が豊富なので、**捏造がそのまま不一致として出る**。

## `null` を認めている

`system.txt` は「原文に無い値は `null`」と指示している。
**埋めようとして捏造するより、空けるほうが良い**という前提。
埋まっているかではなく**一致しているか**で測っているので、この前提が要る。
