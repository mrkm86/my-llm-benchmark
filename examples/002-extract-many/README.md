# 002-extract-many — 3件を1件も落とさない

**測るもの: 001 と同じ抽出を、件数を落とさずやり切れるか。**

| 項目 | 値 |
|---|---|
| ケース数 | 1（1ケースに3件入っている） |
| 1ケースの合否 | JSON 配列で、**件数が一致**し、全オブジェクトの全キーが一致する |
| 段の通過条件 | 全ケース × 全実行（既定3回）が合格 |
| 正解 | **あり**（`cases/*/expected.json`）。**未検品** — `../REVIEW.md` |

## 001 との差は「難しさ」ではなく「やり切るか」

001 が通って 002 で落ちるモデルは、抽出ができないのではなく
**最後まで均一に処理できない**。実測でこの形の落ち方が繰り返し出ている
（3件目の項目が空になる／2件で打ち切る）。

だから **件数の一致を最初に見る**。1件落としても残り2件が正しければ「一致」になる
judge を書くと、この落ち方をまるごと素通りさせる。

## 素材

Michelson & Morley (1887) から、**測定値が1つだけの文**を3本。
001 と同じ理由で、一意に決まる文だけを使っている。
